# Network Routing Simulator

A C++ based simulator that demonstrates how routing algorithms are used in computer networks for efficient packet transmission. The project compares **Dijkstra's Link State Routing** and **Bellman-Ford Distance Vector Routing**, while supporting dynamic network updates and performance analysis.

## Features

- Dijkstra (Link State) Routing
- Bellman-Ford (Distance Vector) Routing
- Routing table generation
- Packet transmission simulation
- Dynamic topology updates (add/remove links)
- Performance metrics including routing time and packet delay

## Tech Stack

- C++
- Graph Algorithms
- Object-Oriented Programming

## Algorithms Used

- Dijkstra's Algorithm
- Bellman-Ford Algorithm
- Distance Vector Routing

## Output

The simulator displays:
- Packet traversal path
- Packet delivery statistics
- Execution time
- Average and maximum packet delay
